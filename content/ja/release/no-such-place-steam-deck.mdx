| 目標とする体験 | 解像度 | レンダースケール | 影の品質 | ポストプロセス | 目標FPS |

## SteamOS クイックアクセス機能と電力管理

ValveのSteamOSクイックアクセスメニュー（QAM）を使用すると、熱設計電力（TDP）、GPUクロック、スケーリングフィルターを細かく制御できます。これらのパラメータを微調整することで、重いシーンでも本体を低温かつ静音に保つことができます。

| パラメータ | 推奨値 | 想定される効果 |
| :--- | :--- | :--- |
| **フレームレート制限** | 45 FPS（または40 FPS） | フレームペーシングの微小なカクつきを解消 |
| **画面リフレッシュレート** | 45 Hz（または40 Hz） | ディスプレイパネルのタイミングと完全に同期 |
| **TDP制限 (W)** | 8W – 10W | 発熱とファンの動作音を抑制 |
| **手動GPUクロック** | オフ (自動) | 負荷に応じた動的周波数スケーリングを許可 |
| **スケーリングフィルター** | FSR (シャープネス: 2) | 細かいUIディテールの輪郭を強調 |

TDPを8W〜10Wの間に制限することで、負荷の低い会話シーンや静止画カットシーンでAPUが無駄にブーストするのを防ぎます。このわずかな調整によって、中断なしの連続プレイ時間を45分〜60分程度延ばすことができます。

## Proton バージョンの比較と互換性検証

**『No Such Place』Steam Deck**でのプレイ中に予期せぬ描画の乱れ、音声のズレ、クラッシュが発生した場合は、Protonの互換性レイヤーを切り替えることでトランスレーション層の競合を直ちに解決できる場合があります。

| Protonレイヤー | 起動ステータス | フレームペーシング | 音声 / 動画再生 | 推奨度 |
| :--- | :--- | :--- | :--- | :--- |
| **Proton デフォルト (Stable)** | 正常起動 | 良好（稀に引っかかりあり） | 完璧 | ほとんどのプレイヤーに推奨 |
| **Proton Experimental** | 正常起動 | 非常に滑らか | 完璧 | 最新の修正を求める場合に最適 |
| **GE-Proton (最新版)** | 正常起動 | 最適なフレームタイム | ビデオコーデックも正常再生 | カットシーンがカクつく場合に最適 |
| **Proton 8.0 Legacy** | 正常起動 | 平均的 | わずかな音声遅延の報告あり | 代替手段としてのみ推奨 |

コミュニティからの報告によると、標準のProton Stableでも大きな問題なく動作します。ただし、最も安定したフレームペーシングを求める場合は、GE-ProtonまたはProton Experimentalを使用することで、オブジェクトが多い屋内環境でもよりタイトで均一なフレーム描画が得られます。

## コントローラー設定とトラックパッドのカスタマイズ

サイコロジカル系や雰囲気重視のアドベンチャーでは、直感的でレスポンスの良い操作性が求められます。デフォルトのゲームパッドレイアウトでも標準的な入力は前面ボタンに割り当てられていますが、トラックパッドの挙動をカスタマイズすることで携帯機での操作感が大幅に向上します。

```
[デフォルト操作の概要]
左スティック -> キャラクター移動
右スティック -> カメラ操作
R2 / RT      -> メインアクション / 調べる
L2 / LT      -> ダッシュ / フォーカスモード
方向パッド   -> クイックインベントリ / ノート
トラックパッド -> メニュー操作＆精密カーソル
```

### 高度なSteam入力マッピング推奨設定

| 入力デバイス | カスタム割り当てアクション | 携帯プレイにおけるメリット |
| :--- | :--- | :--- |
| **右トラックパッド** | マウスとして使用（低感度） | 正確なポインティングとアイテム調査 |
| **右トラックパッドクリック** | インタラクト / マウス左クリック | 親指1本でストレスなくオブジェクト選択 |
| **背面グリップ (L4)** | クイックセーブ / 手帳の開閉 | メニューを開く手間を軽減 |
| **背面グリップ (R4)** | フラッシュライト / ランタンの切り替え | 視点を動かしたまま瞬時に光源を操作 |
| **ジャイロ (タッチ時有効)** | マウスアシスト | 手がかりを調べる際の細かな照準微調整 |

右トラックパッドを低感度マウスカーソルとして割り当てることで、インベントリの整理やパズル画面の操作が格段にやりやすくなり、アナログスティックにはない精密な操作が可能になります。

本体の消費電力を把握しておくことで、充電器を探し回ることなくプレイ計画を立てることができます。以下は、Steam Deck LCD（40Whバッテリー）とSteam Deck OLED（50Whバッテリー）における推定バッテリー持続時間の比較です。

| :--- | :--- | :--- | :--- | :--- |
| **上限なし 60 FPS (デフォルトTDP)** | 約18.5W | 約2時間10分 | 約2時間45分 | 74°C |

## よくある問題のトラブルシューティング

十分に最適化されたインディーゲームであっても、携帯機ならではの問題が発生することがあります。**『No Such Place』Steam Deck**でのプレイ時によく報告される不具合とその解決策は以下の通りです：

- **起動時に入力が反応しない**: Steamオーバーレイを開き、「コントローラー設定」に移動して、キーボード専用テンプレートではなく「ジョイスティックトラックパッド付きゲームパッド」レイアウトが選択されていることを確認してください。
- **通路などでの微小なカクつき**: ゲームのプロパティで「Proton Experimental」を強制適用し、SteamOSを再起動した上で、ディスプレイのリフレッシュレートがフレーム制限値と正確に一致しているか確認してください。
- **字幕が小さすぎる**: ゲーム内のアクセシビリティ設定でUIスケーリングオプションを確認してください。設定項目がない場合は、Steam Deckのショートカット（`STEAM` + `L1`）を使って画面拡大鏡を起動し、小さな文字を読みやすくしてください。
- **クラウドセーブの同期遅延**: 本体のサスペンドや電源オフを行う前に、Wi-Fi接続が完全に再確立されていることを確認してください。Steamクラウドはゲーム終了後、セーブデータとテレメトリのアップロードに少し時間がかかります。

## よくある質問（FAQ）

### 『No Such Place』はSteamOS上でネイティブに動作しますか？
いいえ、本作はProton互換レイヤーを介して動作します。ValveのProtonがWindowsのDirectXやシステムコールをLinux互換の命令へとスムーズに変換するため、特別な設定を行わなくてもネイティブに近いパフォーマンスを発揮します。

### 『No Such Place』をSteam Deckで遊ぶ場合の最適なリフレッシュレートは？
最もおすすめのバランス設定は、45 Hzリフレッシュレートに合わせた45 FPS制限です。この設定にすることで、30 FPSと比べて滑らかさが大幅に向上しつつ、バッテリーを長持ちさせファンのノイズを最小限に抑えることができます。

### Steam Deckで完全オフラインの状態でプレイできますか？
はい、可能です。一度ダウンロードし、必要なシェーダーやランタイムの依存関係をキャッシュするためにオンラインで初回の起動を済ませておけば、飛行機の中や通勤時などインターネット接続がない環境でもプレイできます。

### 小さな画面で字幕サイズを調整するにはどうすればよいですか？
セリフのテキストが小さくて読みにくい場合は、ゲーム内の画面設定を開いて字幕フォントサイズを大きくしてください。また、Steam Deck内蔵の拡大ツール（`STEAM` + `L1`）を使用して、文書や背景にあるメモを素早くズームして読むこともできます。
