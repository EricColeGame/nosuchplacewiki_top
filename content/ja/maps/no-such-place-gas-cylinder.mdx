### 2. セクターB 物流・保管集積所
物流集積所には、積み重ねられた輸送コンテナと油圧荷役プラットフォームが並んでいます。横転した平台トレーラーの間や、コンテナユニットB-07の内部を探してください。このセクターは広々としていますが、射線が長いため、重いキャニスターをゆっくり運ぶソロプレイヤーは狙撃されやすくなります。

## 回収および運搬のステップ別戦略

高圧燃料をマップ全体に運搬することは、チームの連携が試される戦術的な課題です。**no such place gas cylinder**を持ち上げると攻撃能力が大幅に低下するため、事前の準備が最優先事項となります。

```
ステップ1：セクター偵察 ---> ステップ2：チョークポイント排除 ---> ステップ3：ボンベ確保 ---> ステップ4：時間差護衛運搬 ---> ステップ5：端末へ設置
```

運搬時の生存率を最大限に高めるため、以下の手順に従ってください：

1. **静密偵察を実施する**：キャニスターラックに直接突進してはいけません。隣接する通路を偵察し、近接トラップを解除し、巡回ルートのタイミングを把握します。
2. **脱出ルートのクリアリング**：ボンベを拾う前に、予定ルート上にいる徘徊する敵を排除してください。背後の安全を確保することで、重量超過時の待ち伏せを防ぎます。
3. **運搬役と警戒役の割り当て**：協力プレイでは、スタミナ最大値が最も高いプレイヤー、または強固な防御アーマーを装備しているプレイヤーにボンベを持たせます。残りのプレイヤーは前後方の警戒を維持します。
4. **リレードロップ走法の活用**：ソロプレイの場合、全ルートを一気に走り抜けようとしないでください。25メートル運んだら強固な遮蔽物の後ろに慎重に置き、スタミナを回復させてクリアリングを行ってから再び運搬します。
5. **圧力バルブの保護**：高所の足場からボンベを落としたり、階段下に投げ落としたりしてはいけません。急激な物理的衝撃により構造破壊が引き起こされ、瞬時に爆発します。

| :--- | :--- | :--- | :--- | :--- |
| **軽量ランナー** | 100%（基準） | 高（移動速度による音波発生） | 低（サイドアームのみ） | ソロスピードラン、迅速なセクター移動 |

プレイヤーの経験則として、メインの中庭を突っ切るよりも、周囲のユーティリティトンネルを経由した方がはるかに安全です（トンネルルートは約3分の移動時間が余計にかかります）。

## パズル攻略と目標への活用法

**no such place gas cylinder**の確保はミッションのゴールではなく、その後のマップ攻略を進めるためのトリガーです。マッチで発生しているシナリオに応じて、ボンベは3つの主要インフラ端末のいずれかに届ける必要があります。

```
                       [ ガスボンベ ]
                              |
       +----------------------+----------------------+
       |                      |                      |
       v                      v                      v
  [ 補助発電機 ]         [ 防爆扉トーチ ]       [ 脱出エレベーター動力 ]
       |                      |                      |
  (照明の復旧)           (頑丈なロックを切断)      (脱出機能を作動)
```

### 補助発電機の起動
ボンベを発電機ベイにセットすると、セクターCに電力が復旧します。これにより施設の暗い区画が照らされ、敵対生物に対する自動防衛タレットが起動し、研究所の保管庫にあるキーカードリーダーに通電します。

### 緊急防爆扉の突破
ロックダウン中に主防爆扉が密閉された場合、通常の端末ハッキングでは開くことができません。熱切断リグにボンベを装填することで、油圧ロッキングピンを焼き切ることができます。この手順では激しい火花と大きな騒音が発生するため、トーチが作動している90秒間、敵の波状攻撃を防衛する必要があります。

| 端末目標 | 必要燃料数 | インタラクション時間 | 防衛フェーズ | マップへの影響 |
| :--- | :--- | :--- | :--- | :--- |
| **補助発電機** | 満タンのボンベ 1本 | 10秒 | なし（即時通電） | 照明、ドアコンソール、カメラ映像が作動 |
| **防爆扉トーチ** | 満タンのボンベ 1本 | 90秒 | 激戦（敵の攻撃3ウェーブを防衛） | 北部脱出トンネルへの直接ショートカットが開通 |
| **脱出エレベーター** | 満タンのボンベ 2本 | 45秒 | 中程度（エレベーター上昇まで生存） | 高リターンのグループ脱出地点が利用可能になる |
| **除染フラッシュ** | 一部使用済みのボンベ 1本 | 15秒 | 低（換気ハザード） | 中央医療棟から有毒ガスを除去 |

設置を試みる前に、端末のソケットに破片や障害物がないか確認してください。破損したソケットに加圧キャニスターを挿入しようとするとバルブロックが発生し、目標の進行が停止する恐れがあります。

## 重大な生存リスクとその回避方法

敵地で爆発性の積載物を輸送することは、特有の敗北リスクを伴います。環境要因による起爆トリガーを把握しておくことで、不慮の爆発により貴重な戦利品を失う事態を防ぐことができます。

```
[ 被弾 / 破片ダメージ ] 
            +                ---> [ タンク破損（0 HP） ] ---> [ 爆発：致死半径 8.5m ]
[ 高所からの落下（>2m） ] 
```

運搬中は以下の安全プロトコルを徹底してください：

* **環境火災に警戒する**：蒸気孔、アクティブな電気アーク、燃えている残骸はボンベを急速に加熱します。タンクの表面温度メーターがビープ音を鳴らし始めたら、直ちに地面に置き、安全な距離まで退避してください。
* **落下高度に注意する**：エレベーターシャフトや2メートルを超える高さのキャットウォークからボンベを落とすと、外殻の強度が破壊されます。可能な仕様であれば、必ず先にハシゴを降りてから上層のボンベを回収するか、階段を利用してください。
* **角の接触判定に注意する**：整備通路のタイトな角を曲がる際は、カメラを中心に保ってください。コンクリートの壁にタンクをこすりつけると大きな金属音が発生し、周囲の巡回部隊に察知されます。
* **跳弾ゾーンを避ける**：運搬中に銃撃戦に巻き込まれた場合は、強化スチール製バリケードの背後にボンベを置いてください。流れ弾のピストル弾やショットガンの散弾が外装を貫通し、スクワッド全員が爆散する危険があります。

## よくある質問（FAQ）

### No Such Placeでガスボンベが最も安定して出現する場所はどこですか？
プレイヤーの経験とレイドログの集計によると、最も確実な出現ポイントは地下2階の整備作業場内にある施錠された溶接ケージです。次点でセクターB物流集積所の輸送コンテナB-07が高確率となっています。

### ガスボンベはインベントリに入っている状態で爆発しますか？
はい。ボンベを所持した状態で敵にバックパックを撃たれたり、高威力の弾丸が直撃したりすると、コンテナ自体がダメージを受けます。100 HPの耐久値が尽きると、短い噴出音の後に大爆発を起こし、運搬者と周囲の味方に即死級のダメージを与えます。

### 緊急脱出エレベーターを動かすにはボンベが何本必要ですか？
緊急エレベーターを稼働させるには、満タンの燃料ボンベが2本必要です。スクワッドは、危険な密集エリアで重量超過のまま移動する時間を最小限に抑えるため、2本のキャニスターを回収する前に、保管庫からエレベーターシャフトまでのルートを掃討しておく必要があります。

### ガスボンベから火が出始めたらどうすればよいですか？
ボンベが熱ダメージを受けたり、加圧された炎を噴出し始めたりした場合は、即座に手放し、硬い遮蔽物の角を曲がって最低10メートル以上ダッシュで離れてください。約3秒後に大爆発が発生し、爆破半径内にあるすべてが消滅します。
